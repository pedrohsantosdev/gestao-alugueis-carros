# 🚗 gestao-alugueis-carros

Sistema de gerenciamento de aluguel de veículos desenvolvido em Java para fins de estudo, com foco em Programação Orientada a Objetos e tratamento de exceções.

---

## 📌 Funcionalidades

- Cadastro de alugueis  
- Validação de datas  
- Validação de preço por dia  
- Cálculo do valor total do aluguel  
- Cálculo do faturamento total  

---

## 🧠 Conceitos aplicados

- POO (Programação Orientada a Objetos)  
- Encapsulamento  
- Tratamento de exceções  
- Exceções personalizadas  
- Manipulação de datas (LocalDate)
